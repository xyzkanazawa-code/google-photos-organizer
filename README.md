# Googleフォト整理プロジェクト (google-photos-organizer)

マサ専用のGoogleフォト自動整理・Googleドライブ連携スクリプト群です。
自宅のPCでも会社のPCでもそのまま引き継いで開発・実行できるように構成しています。

## 📋 実装済みのブラウザ自動化機能

### 1. ログイン認証の維持
- `browser_data/` にログインセッションを永続化保存。
- 初回のみログインすれば、次回以降はパスワード入力不要で一瞬で起動します。

### 2. スクリーンショットの自動整理 (`organize_screenshots.py`)
- Web版Googleフォトのスクリーンショット一覧を自動で開き、指定枚数をチェック。
- 画面上で確認後、ワンキーでゴミ箱へ移動（手動でチェックを外した写真は残ります）。
- 起動方法: デスクトップの `スクリーンショット整理.bat` をダブルクリック。

### 3. 運行指示書など書類のGoogleドライブ自動移動 (`move_to_drive.py`)
- キーワード（例: 「運行指示書」や「点呼」など）で写真をAI検索。
- 指定枚数を自動選択して一括ダウンロード。
- パソコンの `G:\マイドライブ\運行指示書` フォルダへ自動で保存・展開！
- 保存完了後、Googleフォト側をゴミ箱へ移動して空き容量を増やすか確認。
- 起動方法: デスクトップの `運行指示書をGoogleドライブへ移動.bat` をダブルクリック。

---

## 💻 起動方法まとめ（デスクトップのアイコン）
- **`Googleフォト起動.bat`**: ログイン状態の確認や手動ログイン用
- **`スクリーンショット整理.bat`**: 不要なスクリーンショットの自動整理
- **`運行指示書をGoogleドライブへ移動.bat`**: 運行指示書を検索し、Gドライブへ自動保存
