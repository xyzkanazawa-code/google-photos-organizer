# Googleフォト整理プロジェクト (google-photos-organizer)

マサ専用のGoogleフォト自動整理ツール・スクリプト群です。
自宅のPCでも会社のPCでもそのまま引き継いで開発・実行できるように構成しています。

## 📋 実装予定の2つのアプローチ

### 1. ブラウザ操作の自動化（Playwright / Selenium） 【次回ここからスタート！】
Web版Googleフォト（photos.google.com）をブラウザ自動化ツールで操作し、整理を行うツールです。
- **主な機能案**:
  - 特定の検索ワード（例：「スクリーンショット」「動画」「特定の日付・年」）でヒットした写真・動画の自動選択＆一括削除（ゴミ箱移動）またはアルバム追加
  - 容量を大きく占めている動画や不要ファイルのリストアップ
- **実装のポイント**:
  - Googleのログイン認証を維持するため、既存のChromeプロファイル（または永続化コンテキスト）を利用したPlaywrightスクリプトを作成する。

### 2. Google Takeout（エクスポートデータ）を使った一括整理
Google TakeoutからダウンロードしたZIPデータをPC上で高速に解析・整理するツールです。
- **主な機能案**:
  - 重複写真・類似写真の自動検出＆削除
  - JSONメタデータ・Exif情報をもとにした「年/月」フォルダへの自動振り分け
  - 画像認識AIやルールベースによる不要なスクリーンショット・ピンボケ写真の仕分け
- **事前準備メモ**:
  - 作業する前日などに [Google Takeout](https://takeout.google.com/) で「Google フォト」のエクスポートリクエストを出しておくと、当日待ち時間なしで作業可能。
